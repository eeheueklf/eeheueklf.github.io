## 사이트가 퍼즈됐다는 제보



&nbsp;

나의 사이드 프로젝트인 띵타운은 Vercel로 배포 및 운영되고 있다.

Vercel은 무료 요금인 Hobby, 유료 요금제인 Pro가 있다. 무료와 유료 요금제는 각종 사용량을 기준으로  정해지는데, 띵타운은 네트워크(CDN) 사용량을 가장 많이 쓰고 있다.

![](orca-paste-1793433819093-6bc6158c-e460-4267-b006-7c9b9d20217d.png)

띵타운에 찍히는 Request가 심상치 않았지만, 무료 요금제 안에서 잘 유지되고 있었기 때문에 지켜보고 있었다.

그런데 7월 25일때즈음 서버가 퍼즈가 난 적이 있다. 그때 처음 Edge Request 초과라는 걸 봤고 여러 대응 방법들을 알아봤다.



사용량은 월간 기준으로 집계되기에 25일쯤 초과가 되었으면 거의 막바지에 난거라고 예상을 했고, 일단 Pro 요금제로 결제를 했다 🥹

![](orca-paste-1793683293066-a8e6b79d-56cb-41eb-8eeb-c49705addaf0.png)

### 예상 원인: &lt;Link&gt;

[레딧](https://www.reddit.com/r/nextjs/comments/1hh1myw/vercel_13k_visitors_300k_function_invocations_5/)에서 next/link가 사용자가 해당 페이지로 이동하지 않더라도 다른 페이지를 미리 로드하기 때문에 Request가 많이 일어난다고 해서 다음과 같이 prefetch={false}를 적용해 link에서의 로드를 막았다.

띵타운 상단 메뉴에서의 직업 메뉴들이 미리 불러와지고 있었기 때문에 도움이 됐을 것이다.

![](orca-paste-1793685515367-f8073896-032e-414c-933a-a6efdc82acbb.png)

또한 request 그래프를 살펴보았는데, 오전 3시에 눈에띄게 request가 들어오는 모습을 확인할 수 있었다. 띵타이쿤 게임에서 오전 3시에 시세가 초기화되기 때문에 시세 변경과 조회를 하기 위한 요청이 많이 들어오는구나 싶었지만 따로 고쳐야할 부분은 확인하지 못했다.

### 해결기

![](orca-paste-1793685896248-9d8421ac-b52c-4630-96a0-af7d217d471e.png)

Edge request를 보는데 무료 요금제인 1M을 훌쩍 넘긴 3M가 찍히고 있었다.

근데 뭔가 이상한게 내 사이트가 다른 사이트랑 비교해서 용량이 큰 것도 아니고, 사용자가 300~400명 단위인데 이렇게 찍히는 것은 비정상적인 수치라고 생각이 들었다.



### 원인 1 : 봇

그래서 가장 의심이 갔던 건 크롤러였다.

`robots.ts`에는 `/auth/`만 막혀있어서 AI/상용 크롤러 봇 15종을 추가로 차단했다.

```ts
rules: [
  {
    userAgent: [
      'GPTBot', 'ClaudeBot', 'Claude-Web', 'anthropic-ai',
      'CCBot', 'Google-Extended', 'PerplexityBot',
      'Applebot-Extended', 'Meta-ExternalAgent',
      'Bytespider', 'Amazonbot', 'FacebookBot',
      'AhrefsBot', 'SemrushBot', 'MJ12bot', 'DotBot',
    ],
    disallow: ['/'],
  },
  {
    userAgent: '*',
    allow: '/',
    disallow: ['/api/', '/auth/', '/profile/settings'],
  },
],
```



### 원인 2: 이미지

인터넷에서 또 원인을 열심히 찾았고 [레딧](https://www.reddit.com/r/nextjs/comments/1l74plq/why_does_every_request_count_as_an_edge_request/)에서 이미지 요청이 request를 늘린다는 것을 확인했다!

Vercel에서 `next/image`를 쓰면 이미지가 Vercel의 이미지 최적화를 거치고, 이 요청들이 Edge Request로 집계되어 뻥튀기 된다는 내용이다.

띵타운은 이미지가 많이 쓰이기 때문에 페이지 하나를 열 때마다 이미지 각각이 요청을 만들었기 때문에 발생한 일이었다!

![](orca-paste-1793435342519-951183a2-a03e-435e-b42b-a76b92e25605.png)그래서 이미지를 Cloudflare R2로 옮기고 CDN을 도입했다.

![](orca-paste-1793686987384-c08010e0-7694-48a9-8dcc-9ed52fc89f84.png)
