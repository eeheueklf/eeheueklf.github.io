# 띵타운

인원 | 개인 프로젝트 (기획/개발/운영)
기간 | 2026.05 - Pres.
기술 | Next.js, TypeScript, Supabase, TailwindCSS, Vercel, Cloudflare CDN, Discord OAuth 2.0

> **띵타이쿤 게임 플레이어를 위한 유틸리티·커뮤니티 플랫폼**
> 일 평균 방문자 400명 규모로 운영 중이며, 유저 피드백 30건 이상을 직접 수집해 서비스에 반영하고 있습니다.

---

## 주요 기능

* 최적해 계산기 (Cramer's Rule 기반 선형계획법 알고리즘)
* 스킬트리 빌더 (localStorage ↔ DB 동기화, Debounce 최적화)
* Quick Access 패널 (즐겨찾기 / 최근 방문 / 직업별 기본값)
* 커뮤니티 게시판 및 관리자 승인 시스템
* Discord OAuth 로그인

## 개발 이슈 및 해결 과정

1. **계산 알고리즘 재설계 (0.1ms 이내 일관된 최적해) 🚨**
    * `issue`: 타 서비스 계산기는 입력값이 늘어날수록 계산 시간이 10분 이상까지 증가하며, 휴리스틱으로 개선했으나 결과가 매번 달라지는 일관성 문제가 남아있었습니다.
    * `solve`: 선형계획법의 꼭짓점 성질을 근거로, 가능한 모든 꼭짓점을 `Cramer's Rule`로 직접 계산하여 최적해를 구하는 방식으로 재설계했습니다.
    * `result`: 계산 시간을 0.1ms 이내로 단축하고, 동일한 입력에 대해 항상 일관된 결과를 보장합니다.

2. **Edge Request 99% 절감**
    * `issue`: 서비스 운영 중 Edge Request가 월 300만 건 이상 발생해 유료 플랜 전환이 필요한 수준에 도달했습니다.
    * `solve`: `Vercel Observability`로 추적한 결과 `next/image`를 통한 이미지 요청이 주 원인임을 확인하고, 이미지 제공 방식을 `Cloudflare CDN` 기반으로 전환했습니다.
    * `result`: Edge Request를 기존 대비 약 99% 감소시켜 유료 플랜 전환 없이 운영을 유지했습니다.

3. **OAuth 보안 개선 (httpOnly 쿠키 세션)**
    * `issue`: 클라이언트에서 OAuth 토큰을 직접 처리해 JS에 토큰이 노출되는 구조였습니다.
    * `solve`: 토큰 교환을 `Next.js Route Handler`로 이관하고 세션을 `httpOnly 쿠키`에 저장하여 클라이언트 JS에서 토큰에 접근할 수 없도록 했습니다.
    * `result`: XSS 공격으로부터 인증 토큰을 보호하는 구조를 확립했습니다.

4. **스킬트리 동기화 및 API 최적화**
    * `issue`: 기기 변경 및 브라우저 초기화 시 스킬트리 설정이 유실되고, 연속 클릭 시 다중 서버 요청이 발생했습니다.
    * `solve`: 로그인 여부에 따라 `localStorage`와 `DB`로 분기 저장하여 동기화하고, 1500ms `Debounce`로 연속 클릭 시 API 호출을 묶어 최적화했습니다.
    * `result`: 기기 간 설정이 유지되고, 불필요한 서버 요청을 줄여 운영 비용을 절감했습니다.
